# Project background

`libghostty-swift` is a cohesive Swift Package wrapper for the Ghostty terminal emulation and GPU rendering core. It bridges Ghostty's Zig/C engine into native Swift and AppKit/Metal views for macOS apps like MacSSH.

## Goals
- Provide high-performance GPU-accelerated terminal emulation in Swift.
- Clean C-FFI / Zig bridge with safe Swift memory wrappers.
